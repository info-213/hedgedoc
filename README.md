# HedgeDoc Docker Deployment

Цей проєкт є практичною реалізацією курсової роботи на тему: **«Розробка архітектури та контейнеризація HedgeDoc для забезпечення відтворюваності та масштабованості»**.

## Опис проєкту
Проєкт реалізує автоматизоване розгортання платформи для спільної роботи з нотатками HedgeDoc у середовищі Docker. Використання підходу Infrastructure as Code (IaC) дозволяє швидко розгортати сервіс із гарантованим збереженням даних.

## Технологічний стек
- **Docker & Docker Compose** — контейнеризація.
- **HedgeDoc** — основний застосунок.
- **PostgreSQL** — база даних.

## Структура репозиторію
* `docker-compose.yml` — конфігураційний файл.
* `images/` — папка зі скріншотами підтвердження роботи.
* `README.md` — документація проєкту.

## Інструкція із запуску

1. Переконайтеся, що Docker Desktop запущений.
2. Запустіть сервіси командою в терміналі:
   ```bash
   docker compose up -d
Перевірте стан контейнерів:

Bash
docker compose ps
Відкрийте HedgeDoc у браузері: http://localhost:3000
